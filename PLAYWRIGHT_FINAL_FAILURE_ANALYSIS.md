# Playwright Final Failure Analysis

## Artifact inspection status

- Local Playwright execution created fresh `test-results/**/error-context.md` and trace placeholders, but this container initially has no installed Chromium binary. The local run failed at browser launch before DOM traces could be replayed.
- `npx playwright install chromium` and `apt-get install chromium` were attempted so the failed specs could be reproduced locally with screenshots/traces. Both downloads were blocked by the environment proxy with HTTP 403, so I used the checked-in e2e specs, helper contracts, current UI registry code, and existing generated crawler/result files to identify the remaining deterministic failures.
- The root causes below are tied to the exact failing assertions named by the Playwright specs and the UI code paths those assertions exercise.
