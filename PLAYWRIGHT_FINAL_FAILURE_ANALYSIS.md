# Playwright Final Failure Analysis

## Inspection scope

- Reviewed the requested E2E specs, shared helpers, workspace registry, historical mobile layout code, desktop/mobile navigation, deterministic API mocks, and existing result JSON artifacts.
- Local browser-backed Playwright reproduction was blocked because the Chromium executable is absent at `/root/.cache/ms-playwright/chromium_headless_shell-1223/chrome-headless-shell-linux64/chrome-headless-shell` and `npx playwright install chromium` is blocked by a CDN `403 Forbidden` in this environment.
- The five failures below therefore combine the GitHub Actions failure names supplied in the mission with static/runtime contract inspection of the relevant UI paths and the repository artifacts that were still available.

## Macro regression verification coverage

- Canonical Macro remains `MacroMultiAsset` with aliases such as `Macro`, `Correlation`, and `Beta` resolving through registry helpers.
- Default Macro symbols remain `SPY,NFLX`; beta normalization remains `NFLX` vs `SPY`.
- Deterministic E2E mocks now provide compatible SPY/NFLX datasets and return `ready_multi_dataset` for both correlation and beta.
- Static menu duplicate detection still reports one visible canonical menu entry per workspace.
